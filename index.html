Pertanyaan Sering Diajukan (FAQ)

Bagaimana cara pengiriman file paketnya?

Materi tidak dikirim dalam bentuk buku fisik lewat kurir, melainkan berupa **akses folder Google Drive privat**. Setelah pembayaran, alamat Gmail Anda akan diundang untuk mengakses folder tersebut.

Mengapa aksesnya harus diundang via Gmail?

Demi keamanan eksklusif pembeli. Folder diset dalam mode *Restricted Access* (Terbatas), sehingga hanya alamat Gmail resmi milik Anda yang bisa membuka dan mengunduh filenya.

Apakah materi ini bisa diprint/dicetak sendiri?

Sangat bisa! Semua file berformat PDF/Gambar ukuran standar A4. Anda bisa mencetaknya di printer rumah maupun di tempat fotokopi.

Sampai kapan akses Google Drive ini berlaku?

Akses berlaku **Seumur Hidup (Lifetime)**. Jika file di HP Anda terhapus, Anda tinggal masuk kembali ke Google Drive untuk mengunduhnya.
